# Cursed Dice — เอกสารออกแบบเกม (GDD)

> เอกสารมีชีวิต: แก้ไขได้ตลอดเมื่อเกมเปลี่ยน · สถานะ: **Prototype 0.2**

## 1. ภาพรวม
| | |
|---|---|
| ชื่อ (ชั่วคราว) | **Cursed Dice: ลูกเต๋าต้องสาป** |
| แนว | Dark fantasy adventure / dice-building RPG ต่อสู้ผลัดเทิร์น |
| ภาพ | 2D pixel art โทนมืด แสงเทียน หมอก |
| แพลตฟอร์ม | Android (Google Play) ก่อน |
| ผู้เล่น | เล่นคนเดียว (Co-op 2 คน เป็นแผนหลังวางขาย) |
| Engine | Godot 4 |
| เป้าหมาย | เน้นความสนุก ไม่เน้นหาเงิน กาชาต้องยุติธรรม |

**หัวใจของเกม (one-liner):** ฮีโร่ อาวุธ และสัตว์เลี้ยงทุกอย่าง *เปลี่ยนหน้าลูกเต๋า* ของคุณ การจัดทีมก็คือการสร้างลูกเต๋าของตัวเอง

## 2. เรื่องราว
เทพธิดาแห่งโชคชะตาสร้างโลก **เอลดอร์ร่า** ด้วยลูกเต๋า 6 ลูก วันหนึ่งลูกเต๋าถูกคำสาปกัดกร่อนจนแตกกระจาย โชคชะตาของทุกชีวิตจึงบิดเบี้ยว ซากศพลุกขึ้นเดิน ลัทธิเถ้าธุลีบูชาความเน่า
ผู้เล่นคือ **"ผู้ทอย (Roller)"** คนเดียวที่เรียกวิญญาณฮีโร่จากเศษลูกเต๋าได้ แต่พลังทุกอย่างจากลูกเต๋าต้องสาปต้องแลกด้วยราคาบางอย่าง

## 3. วงจรการเล่น
```
เมือง (อัปเกรด/คราฟต์/เรียกฮีโร่) → เลือกทีม 3 ฮีโร่ + อาวุธ + สัตว์เลี้ยง
→ แผนที่กระดาน (ทอยเต๋าเดิน) → ต่อสู้ / เหตุการณ์ / หีบ / ร้าน
→ บอส → รางวัล → กลับเมือง
```

## 4. ระบบต่อสู้ด้วยลูกเต๋า ✅ (มีใน prototype แล้ว)
**ลำดับในแต่ละรอบ**
1. ฮีโร่ทุกตัวทอยเต๋า 6 หน้าของตัวเอง ส่วนมอนสเตอร์ทอยและ **แสดงเจตนา (Intent)** ล่วงหน้าว่าจะทำอะไรและจะตีใคร
2. ผู้เล่น **ล็อก** ลูกที่ชอบ แล้ว **ทอยใหม่** ได้ 2 ครั้ง และเลือก **เป้าหมาย**
3. กด END TURN: หน้าเต๋าของฮีโร่ทำงานตามลำดับ จากนั้นมอนสเตอร์ทำตามเจตนา

**ชนิดหน้าเต๋า**
| หน้า | ผล |
|---|---|
| ATK | โจมตีเป้าหมาย |
| FIRE | โจมตี และติด **Burn 2** (ไหม้ทุกรอบ ทะลุโล่ ลดลงทีละ 1) |
| BLOOD | โจมตีแรงมาก แต่ผู้ใช้เสีย 2 HP (ไม่ทำให้ตาย) |
| SHIELD | โล่ให้ตัวเอง (หมดตอนเริ่มรอบใหม่) |
| GUARD | โล่ให้ทั้งทีม |
| HEAL | ฮีลเพื่อนที่ HP ต่ำสุด (คิดเป็น %) |
| SWEEP | (มอนสเตอร์) ตีฮีโร่ทุกตัว |
| — (ว่าง) | ไม่มีผล แต่ได้ **+1 Fate** |

**คอมโบ:** หน้าชนิดเดียวกัน 2 ลูก ได้ค่า +1 ทุกลูก ถ้า 3 ลูกได้ค่า **x2**
**Fate (แต้มโชคชะตา):** สูงสุด 5 แต้ม ใช้ 3 แต้มแลกทอยใหม่เพิ่ม 1 ครั้ง (ดวงไม่ดีจึงกลายเป็นทรัพยากร)

**ระหว่างการต่อสู้:** ฮีโร่ที่รอดฮีล +5 HP ส่วนฮีโร่ที่ตายฟื้นกลับมาด้วย 5 HP

### สกิลพิเศษ ✅ (0.2)
- ทุกรอบที่จบเทิร์น ฮีโร่ที่ยังมีชีวิตได้ **Charge +1** และถ้าหน้าเต๋าของตัวนั้นอยู่ในคอมโบ ได้เพิ่มอีก +1
- เริ่มการต่อสู้ด้วย Charge 0 เมื่อ Charge เต็มกดใช้ได้ทันทีในช่วงวางแผน ใช้แล้ว Charge กลับเป็น 0
- **ทุกสกิลมีราคา** ตามธีมดาร์กแฟนตาซี

| ฮีโร่ | สกิล | Charge | ผล | ราคาที่ต้องจ่าย |
|---|---|---|---|---|
| Varek | **Broken Oath** | 4 | โล่ +5 และดึงการโจมตีเดี่ยวของศัตรูทุกตัวมาที่ตัวเอง | ต้องรับดาเมจแทนทุกคน |
| Lys | **Hollow Flame** | 5 | ดาเมจ 4 ใส่ศัตรูทุกตัว + Burn 1 | เสีย 3 HP (ไม่ตาย) |
| Aldric | **Last Rite** | 6 | ฮีลทุกคน 3 และชุบชีวิตเพื่อน 1 คน (4 HP) | เสีย 3 HP (ไม่ตาย) |

**บันทึกบาลานซ์ 0.2:** ตอนแรก Last Rite แรงเกินไป (ชนะ 98% แม้เล่นแบบไม่คิด) จึงลดค่าฮีล/ชุบชีวิต และเพิ่มราคา HP ส่วนบอสเพิ่ม HP เป็น 70 และมี Sweep 2 หน้า ผลจำลองเล่นแบบไม่คิด: ชนะ **58%**

**แผนต่อไป:** ธาตุ 6 ธาตุ, ระดับดาว, ฮีโร่ใหม่ (โจร, นักพนัน, นักล่าแวมไพร์ ฯลฯ) แต่ละตัวมีสกิลของตัวเอง

## 6. มอนสเตอร์ ✅ (4 ชนิด)
Ghoul, Ash Cultist (ฮีลพวกเดียวกัน), Bone Hound (ตีแรงแต่ว่างบ่อย), **บอส The Rotting Bishop** (HP 70, ATK6 ATK8 SWEEP4 SWEEP5 SHIELD6 HEAL5)
**แผน:** บอสหลายเฟส, มอนสเตอร์ที่เปลี่ยนหน้าเต๋าของผู้เล่น, สมุดภาพมอนสเตอร์ (Bestiary)

## 7. อาวุธ ⏳
อาวุธ **แทนที่หน้าเต๋า 1–2 หน้า** ของฮีโร่ที่ถือ เช่น *ดาบเถ้าถ่าน*: แทนหน้าว่างด้วย FIRE 4
อัปเกรดได้ +1 ถึง +5 คราฟต์ได้จากวัตถุดิบที่มอนสเตอร์ดรอป
**อาวุธต้องสาป:** แรงกว่าปกติ แต่เพิ่มค่า Corruption

## 8. สัตว์เลี้ยง ⏳
มีเต๋า d4 ทอยเสริมทุกรอบ พร้อมความสามารถติดตัว ได้จากการฟักไข่ เลี้ยงดูแล้ววิวัฒนาการ (d4 → d6)
ตัวอย่าง: อีกาวิญญาณ (เห็นเจตนาศัตรูล่วงหน้า 2 รอบ), หมาป่าเงา (+1 ATK), มังกรกระดูกตัวน้อย (FIRE)

## 9. Corruption (ความเสื่อม) ⏳
ใช้พลังต้องสาปแล้วจะสะสมค่านี้ ฮีโร่แข็งแกร่งขึ้น แต่หน้าเต๋าบางหน้าจะกลายเป็น 💀 ที่ทำร้ายตัวเอง ล้างได้ที่โบสถ์ในเมืองโดยต้องจ่ายราคา

## 10. แผนที่และภารกิจ ⏳
- แผนที่กระดาน ทอย d6 เพื่อเดิน (มีของที่ให้ทอย 2 ลูกแล้วเลือก)
- 6 ภูมิภาค: Hollow Road → ทะเลทรายเถ้า → ป่าหิมะศพ → ภูเขาไฟ → เมืองลอยฟ้าที่ล่มสลาย → ปราสาทเงา
- ภารกิจหลัก ภารกิจรอง ภารกิจรายวัน/รายสัปดาห์
- Endgame: **หอคอยโชคชะตา** แต่ละชั้นสุ่มกฎพิเศษ

## 11. กาชา (Summon Roll) ⏳
- สุ่มฮีโร่และอาวุธด้วยค่าเงินที่ **หาได้จากการเล่นทั้งหมด**
- การันตี 5★ ทุก 50 ครั้ง ได้ตัวซ้ำเปลี่ยนเป็นเศษดาวไว้แลกตัวที่ต้องการ
- ฮีโร่ในเนื้อเรื่องหลักได้ฟรีทุกตัว และต้องผ่านเกมได้โดยไม่ต้องสุ่ม
