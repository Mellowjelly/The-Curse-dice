# Cursed Dice: Privacy Policy / นโยบายความเป็นส่วนตัว

_Last updated: 2026-11-26_

## English
Cursed Dice is a single-player offline game.

- **No personal data is collected.** The game does not ask for your name, e-mail, location, contacts or any account.
- **No internet connection is used.** The game sends nothing to any server. There are no ads, no analytics and no tracking.
- **Saved data stays on your device.** Your progress and settings (language, volume) are stored only in the game's own folder on your phone. Uninstalling the game deletes them.
- **No purchases with real money** are required to play. All in-game currency is earned by playing.
- **Children:** the game collects no data from anyone, including children.

If this policy changes (for example, if an optional feature ever needs the internet), the new version will be published here before the update is released.

## ภาษาไทย
Cursed Dice เป็นเกมเล่นคนเดียวแบบออฟไลน์

- **ไม่เก็บข้อมูลส่วนตัว** เกมไม่ขอชื่อ อีเมล ตำแหน่ง รายชื่อติดต่อ หรือบัญชีใดๆ
- **ไม่ใช้อินเทอร์เน็ต** เกมไม่ส่งข้อมูลไปที่เซิร์ฟเวอร์ใด ไม่มีโฆษณา ไม่มีระบบวิเคราะห์ ไม่มีการติดตาม
- **ข้อมูลเซฟอยู่ในเครื่องของคุณ** ความคืบหน้าและการตั้งค่า (ภาษา ระดับเสียง) เก็บไว้เฉพาะในโฟลเดอร์ของเกมบนมือถือ ลบเกมแล้วข้อมูลจะหายไปด้วย
- **ไม่ต้องจ่ายเงินจริง** เพื่อเล่น สกุลเงินในเกมทั้งหมดได้จากการเล่น
- **เด็ก:** เกมไม่เก็บข้อมูลจากใครเลย รวมถึงเด็ก

หากนโยบายนี้เปลี่ยน (เช่น ถ้ามีฟีเจอร์เสริมที่ต้องใช้อินเทอร์เน็ต) จะประกาศฉบับใหม่ที่นี่ก่อนปล่อยอัปเดต
