# ประวัติการทดสอบ: จาก 0.2 ถึง 1.0

ทุกเวอร์ชันผ่านวงจร: **บอทเล่นจริง → นักวิจารณ์ AI 4 คนวิจารณ์ → แก้ → เวอร์ชันถัดไป**
รายละเอียดเต็มอยู่ใน `docs/playtests/<เวอร์ชัน>/` (report.md = ตัวเลข, critique.md = คำวิจารณ์, transcript_*.txt = บันทึกการเล่นทั้งเกม)

## ปัญหาใหญ่ที่การทดสอบจับได้
- **0.2:** ง่ายเกินไป และเล่นเก่งกับเล่นไม่คิดชนะพอ ๆ กัน → เพิ่มแผนที่และความเสียหายสะสม จนช่องว่างระหว่างเล่นเก่งกับไม่เก่งเป็น 15-30%
- **0.2-0.4:** แทบไม่มีใครใช้ Fate → Fate ได้จากคอมโบและชัยชนะ, มี Fate Twist, Fate ล้นกลายเป็นทอยฟรี, มีป้ายเตือนเมื่อ Fate เต็ม
- **0.3:** ตัวเลือกเดินครึ่งหนึ่งเป็นตัวเลือกปลอม (Fight กับ Fight) → ทอยใหม่อัตโนมัติให้ปลายทางต่างกัน
- **0.4:** Candle Moth แรงเกิน (ชนะ 95-100%) → ปรับจนสัตว์ทุกตัวต่างกันไม่เกิน ±8%
- **0.5:** **บั๊กจริง** ช่องบังคับหยุดไม่ทำงาน เพราะ JSON เก็บตัวเลขเป็นทศนิยม (21.0 ≠ 21) → แก้และมีเทสต์
- **0.5:** อัปเกรดในเมืองแรงเกิน (มือใหม่ชนะ 90%+ ตั้งแต่รันที่ 2) → ลดพลังและขึ้นราคา
- **0.6:** ทีมที่ดีที่สุดกับแย่ที่สุดห่างกัน 46 จุด → ให้หน้าเต๋าฟื้นฟูกับฮีโร่ที่อ่อน เหลือห่างประมาณ 24 จุด
